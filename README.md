### Qué hago?

-  *Computer Vision*: reconocimiento facial (InsightFace, OpenCV, MediaPipe), detección de objetos (YOLOv7–v11)
- *OCR*: extracción de texto con PaddleOCR, EasyOCR y Tesseract usando validación cruzada
- *Edge AI*: despliegue y optimización de modelos en NVIDIA Jetson (TensorRT, ONNX) para inferencia en tiempo real
- *Mobile ML*: modelos TensorFlow/TFLite desplegados en iOS (Swift + AVCapture) y Android (Kotlin + CameraX)
- *Vector Search*: embeddings y búsqueda semántica con Qdrant
- *Backend & Infra*: APIs en Python, contenedores Docker, trabajadores en background, MySQL/MariaDB
- *Vibe Coding*: uso agentes de IA colaborativos y herramientas de IA generativa para acelerar el desarrollo y automatizar tareas repetitivas
